# Weddinger

Weddinger is a full-stack wedding planning application designed to simplify the complex process of organizing a wedding. It helps couples manage their budget, track payments, and discover curated vendors in one intuitive interface.

## 🚀 Features

Budget Management: Create, track, and categorize expenses. Automatically calculate remaining funds.
Expense Visualization: Interactive pie charts providing a clear overview of budget utilization.
Vendor Directory: A curated list of partner venues and services with status tracking.
Modern UI: A clean, responsive interface built for both desktop and mobile devices.

## 🛠 Tech Stack

**Backend**: Framework: FastAPI (Python), Database: PostgreSQL/MySQL, Data Validation: Pydantic, ORM: SQLAlchemy
**Frontend**: Framework: React, Styling: Tailwind CSS, Icons: Lucide React, Charts: Recharts
